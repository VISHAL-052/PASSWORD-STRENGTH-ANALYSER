# 🔐 Password Strength Analyzer

A modern cybersecurity-focused web application that analyzes password strength using entropy calculation, pattern detection, and password hashing techniques.

## 🚀 Features

- Password strength analysis
- Entropy calculation
- Common password detection
- Predictable pattern detection
- Strong password suggestion generator
- Password hashing using bcrypt
- Password verification system
- Premium modern UI with Flask
